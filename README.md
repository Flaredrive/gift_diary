# Gift Diary

## サイト概要
　プレゼントのレビューを書くレビューサイト。バイヤー主導のランキングではなく、利用者の投稿によりランキングが決まっていく。

### サイトテーマ
　プレゼントを選ぶ際に参考にすることを目的としたレビューサイト。
​
### テーマを選んだ理由
　プレゼント選びをするとき、私はよくランキング形式のギフト紹介サイトを参考にしてきました。しかし、そこで提示されるランキングは、基本的に少人数のバイヤーが「できるだけ客観的に」作成したものであり、どうしても個人の主観が混ざります。さらに、客観性を保つ必要があるため、実際の利用者が感じたような、庶民的でリアルな体験や背景はほとんど書かれません。
　一方で、プレゼント選びで本当に役立つのは、「このプレゼントを贈ったら、こういう理由で喜んでもらえた」といった、実際の体験に基づく主観的なレビューだと感じています。たとえその商品を自分が贈る予定でなくても、誰かのリアルな経験は選択のヒントになります。
　そこで私は、完全に主観によるプレゼントレビューを自由に投稿できるサイトを作ろうと考えました。さらに、投稿数や「参考になった」評価をもとにランキングを生成することで、バイヤー一人の視点ではなく、多くの利用者の声を反映したプレゼント選びができるようにしました。
　このサイトは、従来の「客観的ランキング」では拾いきれない、人の気持ちや背景まで含めた“リアルなプレゼント選び”を実現したい  という思いから制作したものです。
​
### ターゲットユーザ
　プレゼント選びに悩んでいる人
　プレゼントを贈ることによる喜びをだれかと共有したい人

### 主な利用シーン
　プレゼント選びに悩んだとき
　プレゼントに成功してうれしかったとき
